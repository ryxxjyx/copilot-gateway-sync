# Copilot 网关模型管理 0.4.4

API基础地址末尾没有`/v1`时自动补上；已有`/v1`或`/v1/`不重复添加。保存、列表获取、检测和生成Copilot模型URL共用该规则。自定义路径如`/proxy`变成`/proxy/v1`。旧记录无须重新输入Key；保存时地址按相同规则比较，避免误报更换地址。

安装范围声明为 VS Code 1.80+（包括1.135）；已在1.139.1真实宿主回归，1.80–1.138未逐版实测。旧宿主缺少Copilot原生命令时明确阻止新建安全模型组，不降级为明文凭据；已绑定且文件有效的配置仍可通过原有安全文件流程同步。填写网关地址和Key → 同步模型列表 → 检测 → 确认应用到Copilot。无需安装OpenCode、Bun或Python才能使用VSIX。

## 安装

从VS Code扩展视图菜单“从VSIX安装”选择 `copilot-gateway-sync-0.4.4.vsix`，重新加载窗口。在扩展详情页选择 **齿轮 → 扩展设置 → 打开网关模型管理**，在单独的管理标签页配置供应商。重复打开会聚焦同一面板；关闭后可以重新打开。命令面板的 **Copilot: 打开网关模型同步** 仍可作为备用入口。确认面板显示v0.4.4。未自动安装到生产profile。

原生设置页仅提供管理入口，并非嵌入完整表单。`gatewaySync.intervalMinutes` 是保留的旧版设置，当前不控制自动刷新；实际开关及间隔在管理面板中按供应商配置。入口不新增检测、网关请求或模型应用，既有启动及自动刷新行为保持不变；供应商配置和Key存储方式不变，Key仍保存在SecretStorage，不写入普通设置。

## 删除供应商（0.4.2）

左侧选中已保存服务后，点击“删除当前供应商”并确认。会停止自动刷新、清理本扩展管理的Copilot模型、删除本扩展保存的API Key及供应商记录。未绑定服务不访问Copilot文件；清理不请求网关，不需要API Key有效。非本扩展管理的手动模型、其他组和设置保留；绑定管理组清理后为空时，整个组及apiKey配置引用一起删除；有手动模型时保留其组及引用并提示。仅清理JSON引用和本扩展保存的Key，不宣称删除Copilot密钥库中的独立凭据。旧版本已删除供应商后遗留的无绑定空组不会自动扫描删除，需要核对后单独清理。

删除进行中禁用重复操作。失败会保留已停用条目并说明完成阶段，处理问题后可重试；不是跨文件/SecretStorage原子事务。删除最后一个服务后显示新增表单。模型列表中的“移除”仍只移除筛选模型，不删除供应商。

## 批量应用修复（0.3.5）

批量检测中某模型触发限流/认证失败或用户取消，不再撤销其它已完成模型的检测结果。顶部“应用”逐模型检查，确认框列出可应用项与跳过原因；不会因一个中断、配置过期或推理默认保护项阻止其它正常模型。跳过项不会偷偷使用未验证结果，也不会清除其诊断信息。模型行“应用”和顶部使用同一规则，无需为已完成模型重新单项检测。成功、取消或错误信息显示在模型列表上方；若全部不可应用，明确列出原因。

## 四个主按钮（检测/取消同位置切换）

- **同步**：读取网关模型列表，同步已选择的模型，不自动添加新模型；也可重试本地待同步配置。
- **检测**：对当前筛选范围统一检测协议、文本、工具、图片、推理档位。先确认最大请求数及费用。
- **检测 / 取消检测**：同一个按钮。确认开始检测后变为“取消检测”，结束/取消/失败后恢复“检测”。单模型检测和面板重开也可从顶部取消；同步等非检测操作时禁用此按钮。
- **应用**：预览后确认，将筛选模型添加到Copilot，应用有效推荐协议及正向验证工具/图片能力。保留上下文和输入输出上限，不自动关闭未确认能力。未检测模型要求已确认模板/用户覆盖/可靠网关元数据；过期或中断的检测必须重测。
- **移除**：只移除当前筛选范围中已添加的模型，不删除其它范围或其它供应商模型。

每模型保留配置、检测、应用、移除操作。连接设置及高级设置折叠展示，避免重复按钮。

## 高并发与可填写超时

展开“检测设置 / 高级操作”：

| 参数 | 新安装默认 | 可填写范围 |
|---|---:|---:|
| 全局并发 | 32 | 1–128整数 |
| 同模型并发（跨协议共享） | 8 | 1–32整数 |
| 单项超时（秒） | 30 | 1–600整数 |

旧版已保存的并发和超时会保留，不静默提高请求压力；已有6并发需要手动填写32或其它值。参数在检测开始前校验并保存，无额外保存按钮。高并发不保证网关更快，可能导致限流；401/429停止新增请求，不自动重试，403停止对应协议分支。取消后仍可看到真实已执行项目数。

## 统一检测，减少重复请求

- 每模型独立流水执行，慢模型不阻塞其它模型进入下一阶段。
- 先测当前协议文本，再并发测试工具/图片；三项全通过直接执行推理档位，不比较其他协议速度。
- 有失败/超时/未确认项时比较另外两个协议，复用本轮当前协议结果，绝不重复请求。
- 可勾选“强制完整三协议比较”，仍复用当前协议的三项。
- 比较候选要求文本及已声明工具/图片通过，能力优先，之后按共同成功项目耗时排序，差距20%内保持原协议。无推荐继续当前协议推理检查（权限/认证/限流终止除外）。单轮结果不是长期最快保证。
- 默认5个推理候选时：正常模型8请求；回退/强制全比较最多14请求，旧版分开比较9+完整8共17请求。声明档位数量不同则按实际预算计算。
- 常规每项最多128输出token，推理每项最多1024，仍受模型输出限制约束；不为提速缩减原推理检查范围，不自动重试，不读取用户对话/代码/图片。
- 进度区区分**已检测、跳过、按策略省略**；省略不是能力通过，进度100%不是全项成功。等待只显示耗时/剩余超时秒数，不伪造服务端百分比。
- `xhigh`/`max`仅候选。请求成功不能证明服务端未忽略推理参数；有显式默认推理档位时仍保守阻止自动切换新协议，先清除默认并重测。工具测试不执行函数，不验证完整Agent续接；图片仅验证内置合成颜色；不测PDF/音频/视频或极限上下文。

## 上限与配置持久化

支持1M=1000000、128K=128000或整数。保存失败保留草稿及弹窗；先持久化本地再同步Copilot，失败明确标记“本地已保存，Copilot未同步”。已有供应商可独立保存默认能力模板，无需模型列表接口成功。

优先级：逐模型用户覆盖 > 网关可靠能力/最大限制 > 用户模板。新增供应商预填 messages、总上下文1000000、最大输出256000；最大输入留空，工具/图片/推理开关开启，推理候选为 low,medium,high,xhigh,max，默认思维级别留空（跟随 Copilot / 服务器）。这些是用户可编辑的初始模板和候选，不是网关实测能力或上限；应用未检测的模板模型仍需显式勾选确认。已保存供应商模板和逐模型覆盖保持原值，不自动迁移为新默认。不得凭名称猜上限。部分网关context/input/output元数据会保留，组合不合法时提示而非默默采用。

配置弹窗可恢复网关最大限制；高级设置可批量应用网关最大限制，确认后仅替换已提供字段，未知项保留。默认模板不覆盖已有逐模型设置。输入与输出不能同时占满上下文；Copilot有效输入预算为 `min(maxInputTokens, contextWindow-maxOutputTokens)`。默认推理档位写入原生模型组settings，不当作普通model字段。

## 同步与安全

支持多供应商，列表固定使用OpenAI兼容 `/models`；已移除列表接口选择和提供商ID字段。旧OpenCode列表源在加载时归一化为models，不改变已有模型API协议和用户上限。自动刷新默认每60分钟，仅VS Code运行时，同步已有选择，不重新添加已移除模型。关闭自动刷新可停用定时同步，不修改旧脚本计划任务。

Key保存在VS Code SecretStorage；Copilot使用原生安全引用，不将明文Key写JSON。不接管原有手工模型组。已绑定地址/Key更换要求新建供应商。HTTPS优先，HTTP首次确认明文传输；拒绝重定向，不跳过证书验证。

配置写入使用锁、备份和原子写入，保留无关组。原生命令定位当前profile；初次创建组可能格式化JSONC。备份保留10份，文件有未保存编辑时停止。不要删除锁文件来强行覆盖正在运行的写入。

## 验证与开发

本版用本地HTTP mock及隔离VS Code测试，不调用公司收费网关，不写生产配置。最终交付说明列出准确测试数量及基准。UI仅自动化DOM验证，未宣称人工视觉验收。

```text
bun install
bun run typecheck
bun test tests
bun tools/benchmark-034.ts
bun run build
bun run package
```

`benchmark-034.ts`使用15模型、相同120请求对比6/2与32/8调度及统一检测，固定40ms loopback延迟，不外推真实网关。

设置VSCODE_EXE指向Code.exe后执行`bun tools/run-host.mjs`可验证隔离源码宿主；参数传VSIX路径则验证隔离安装。每次新建临时user-data-dir与extensions-dir。发布包在上级deliverables，源码不包含node_modules、profile或日志。依赖VS Code原生内部模型组命令，缺失时明确报错，不降级明文凭据。
